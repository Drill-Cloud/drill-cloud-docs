# Расследование инцидентов

Цель — пройти от пользовательского симптома к первичной причине, сохраняя одинаковое временное окно на всех экранах.

## Что зафиксировать в начале

- контур: DEV, ALPHA или PROD;
- время события в MSK;
- UI, API или конкретная функция;
- edge/topic/camera, если известны;
- версия или время последнего деплоя;
- скриншот симптома и ссылка на дашборд с выбранным интервалом.

## Сервис недоступен

1. **Обзор бизнес-контуров** — подтвердить UI/API `DOWN`.
2. **Доступность контуров** — найти время первого провала и HTTP status.
3. Дашборд окружения — контейнеры, CPU, RAM, cAdvisor.
4. Backend и UI логи в том же интервале.
5. Если есть DB/SQL/timeout — PostgreSQL; если данные не поступают — MQTT-ingest и Monitor.
6. Если затронуто несколько сервисов — сервер и система мониторинга.

## В UI нет свежих данных

1. Проверить Backend API и HTTP status.
2. Проверить, есть ли сетевой трафик у общих сервисов.
3. В MQTT-ingest найти topic/edge и первый `failed`/timeout.
4. В Monitor проверить состояние того же канала.
5. В Backend проверить ingest/API и ошибки БД.
6. В PostgreSQL проверить соединения, rollback и логи.

## Высокая задержка без `DOWN`

1. Сравнить длительность HTTP-проверки с предыдущим стабильным периодом.
2. Проверить CPU/RAM конкретных контейнеров.
3. Проверить Load average, iowait и Disk I/O хоста.
4. Проверить старую транзакцию, подключения и rollback PostgreSQL.
5. Сопоставить начало роста с релизом или тестовым запуском.

## На панели `No data`

1. Сбросить поиск в `.*`.
2. Расширить период до 6 или 24 часов.
3. Проверить выбранные stack/container.
4. Для ресурсов проверить cAdvisor/Prometheus target.
5. Для логов проверить Loki и Alloy.
6. Для БД проверить postgres-exporter и соединение.

## После локализации

Запишите короткий итог: симптом, затронутый контур, начало, первичная причина, временное решение и постоянное исправление. Если проблема воспроизводится пользовательским сценарием, запустите соответствующий [профиль автотестов](../testing/profiles.md) и приложите ссылку на GitHub Actions/ReportPortal.
